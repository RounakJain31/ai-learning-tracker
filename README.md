# AI Learning Tracker

## 🚀 Overview
A full-stack application that helps students track learning topics and get AI-powered suggestions.

## 🧠 Features
- CRUD Topics
- Authentication (NextAuth)
- PostgreSQL Database
- AI Suggestions
- Responsive UI

## 🏗️ Tech Stack
- Next.js 16
- TypeScript
- PostgreSQL + Prisma
- Tailwind CSS
- OpenAI API

## 🔐 Security
- Input validation
- Secure auth
- API protection

## ⚙️ Setup

```bash
npm install
npx prisma migrate dev
npm run dev
